# Тень — учебное бронирование билетов

## Тема

Кинотеатр «Тень»: посетитель выбирает один из двух сеансов фильма «Человек-паук: Новый день», отмечает несколько свободных мест на плане зала 4 × 6 и получает учебный билет. Ряды A–B относятся к зоне «Стандарт» (420 ₽), ряды C–D — к зоне «Комфорт» (560 ₽).

## Запуск

Самый простой способ — дважды щёлкнуть файл **«Запустить сайт.bat»**. Он поднимет локальный сервер и откроет страницу в браузере. Не закрывайте появившееся свёрнутое окно сервера, пока пользуетесь сайтом; чтобы остановить демо, закройте это окно.

Проект не требует npm или сборщика. Если предпочитаете запуск вручную, откройте папку в редакторе и запустите index.html через Live Server. Либо из папки проекта запустите любой локальный HTTP-сервер, например:

~~~powershell
python -m http.server 8000
~~~

Затем откройте http://localhost:8000.

## Возможности

- Два сеанса с разной исходной занятостью.
- 24 места, построенные из одного массива данных; одинаковый выбор работает на плане и в списке.
- Фильтры по сеансу и ценовой зоне.
- Выбор нескольких свободных мест и расчёт общей суммы.
- Подтверждение билета, просмотр «Моих билетов» и отмена брони.
- Сохранение в localStorage по одному ключу; повреждённые данные и ошибки хранилища показываются пользователю.
- Адаптивная раскладка, клавиатурное управление и видимый фокус.

## Ограничения

Это учебное демо без регистрации, сервера и оплаты. Билеты сохраняются только в localStorage текущего браузера и не являются реальной бронью.

## Источники и инструменты

Для афиши используется изображение, предоставленное пользователем, сохранённое в assets/spider-man-new-day.webp. Внешние шрифты и сторонние ресурсы не подключаются. Код подготовлен с помощью ChatGPT/Codex на ванильных HTML, CSS и JavaScript ES-модулях.
